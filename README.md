# Business Management Engine

## Project Overview

Business Management Engine is a Core Java application developed using Java 17 and Maven.

The project demonstrates object-oriented programming, collections, generics, streams, lambda expressions, custom exceptions, Java records, JUnit 5 testing, and Maven project management.

## Technologies Used

- Java 17
- Maven
- JUnit 5
- Eclipse IDE
- Git
- GitHub
